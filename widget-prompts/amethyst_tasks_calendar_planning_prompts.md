# Tasks, Calendar & Planning

## 1. Backlog Widget (`task.backlog`)

Design a premium Apple-inspired **Backlog widget** for a desktop dashboard. Generate multiple distinct Small, Medium and Large variations.

Explore these design directions:
- Minimal: backlog count with the next task to tackle.
- Priority-focused: separate urgent tasks from everything else.
- Grouped: organize tasks by project or category.
- Timeline: show how long tasks have been waiting.
- Editorial: highlight one recommended task with supporting items.

**Small**

Show the backlog count, one priority task and a compact priority indicator.

**Medium**

Show 4–6 tasks with title, project, priority and age. Include a compact backlog summary.

**Large**

Show 8–12 tasks grouped by project or priority. Include task age, status, priority and a clear indication of what deserves attention first.

**Visual direction**

Use Apple-level typography, restrained colours, subtle dividers and varied corner radii. Explore compact lists, grouped sections and split layouts. Support light and dark appearances. Use colour sparingly to distinguish priority and age.

Make every variation compositionally different. Use believable backlog data. Avoid generic cards, excessive pills, gradients and unnecessary charts.
