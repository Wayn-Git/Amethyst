# Shipped widget map

Source: backend/dashboard/registry.py MANIFESTS. Check with `.venv/bin/python scripts/check-widget-map.py`. All values and actions below remain owned by existing providers and components. Fields list the payload keys read by that component; shared components consume the subset provided for each ID.

## State contract (applies to every row)

Loading: static skeleton and reserved content footprint. Empty: manifest empty text; editable widgets keep their add/settings form. Error: alert text and Retry. Stale: original payload remains with stale/freshness chip. Not connected: source-specific Connect action; locally configured widgets retain their existing setting disclosure. Refresh and last-synced remain in the header. Sizes grow for real text and controls, never scroll inside a tile. Every state/size is available in the labelled development gallery. Fixtures never replace live payloads.
